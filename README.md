# Hourhouse

A small members' room. Write at the desk. Private by default. Mark a slip public and it can take the hour.

## Env

```
NEXT_PUBLIC_SUPABASE_URL=https://tqfocdktvjuwoiyfgesb.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

Deploy on Vercel and add those two env vars. Then Import the GitHub repo.
